PURPOSE of this APPLICATION:   

This is a simple command line Python application.  
It requests the user's input for a 2-letter abbreviation of a country, using the standard "alpha2Code" for countries.  
The program uses the inputted letters to return the relevant country, capital city, and population of the country.

API & dataset used:

Countries (countries.dev)
A database of every country in the world, with data on population, area, region, languages, capital city, and more.

Base endpoint: https://countries.dev/countries
